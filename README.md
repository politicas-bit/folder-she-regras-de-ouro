# Folder SHE

Página simples para publicar no GitHub Pages e acessar via QR Code.

## O que inclui
- 10 Regras de Ouro SHE
- 10 Boas Práticas de Fabricação
- Confirmação de leitura com nome e data
- Botão para registrar a leitura no navegador

## Como publicar no GitHub Pages
1. Envie este arquivo `index.html` para um repositório no GitHub.
2. Ative o GitHub Pages nas configurações do repositório.
3. Use a URL publicada como destino do QR Code.

## Observação importante
O registro atual é salvo apenas no navegador com `localStorage`.
Se você precisar de rastreabilidade real com histórico centralizado, eu posso adaptar para:
- Google Forms / Microsoft Forms
- Planilha no Excel ou Google Sheets
- Banco de dados ou API
